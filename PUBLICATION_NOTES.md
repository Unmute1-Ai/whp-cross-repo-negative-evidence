# Publication notes (framing)

## Three places — different detail

1. **GitHub verification/evidence repo (canonical)**  
   - `CROSS_REPO_VERIFICATION.md` (human-readable)  
   - `cross_repo_negative.json` (machine-readable)  
   - Harness sources used for the run  

2. **GitHub Release / tagged evidence artifact**  
   - Tag/name: `cross-repo-negative-2026-09-19`  
   - Attach: tarball + `SHA256SUMS`  
   - Ties result to exact harness files via hashes  

3. **Public DIP verification page**  
   - Short section only  
   - Use the concise statement in `PUBLIC_SNIPPET.md`  
   - Link to canonical record + release  

## What not to post

- “Wheeler Hubbell passed a 15/15 security audit.”  
- “100% secure.”  
- Any implication that funded mainnet or private execution was verified.

## Correct name

**Independent Cross-Repository Negative Verification — 15/15 PASS**
